# Sanctuary: Personal Focus Workspace 🌸

Sanctuary is a sleek, distraction-free Pomodoro timer and ambient audio dashboard designed to optimize deep work, study flow, and exam preparation. Built completely with lightweight, zero-dependency HTML5, CSS3, and JavaScript, it is optimized to run flawlessly when hosted via **GitHub Pages**.

## ✨ Features

- **Aesthetic UI:** A clean glassmorphism interface backed by a calming, high-fidelity anime study-room aesthetic.
- **Immune Audio Engine:** Features 4 real-world, high-quality audio streams (Gentle Drizzle, Lofi Piano, Forest Birds, Ocean Waves) streamed securely from public repositories—bypassing local file restrictions and CORS blocks entirely.
- **Rhythm Mixer:** Mix and match different ambient background tracks with custom volume controls to create your perfect study environment.
- **Writable Aim Tracker:** A custom HUD where you can type in your specific target goals (e.g., `JEE 2027`, `NEET`, `UPSC`).
- **Persistent Countdown Matrix:** Select your exam or target date using the built-in calendar tracker to dynamically view exactly how many days you have left. Your data is automatically saved to browser local memory, ensuring it never disappears when you refresh the page.

## 🚀 Quick Setup & Deployment

1. Create a new public or private repository on GitHub.
2. Upload the `index.html` file directly to the root of your repository.
3. Head over to **Settings** -> **Pages** inside your repository.
4. Set the build source branch to `main` (or `master`) and hit **Save**.
5. Open your generated live URL, click anywhere on the background once to grant audio authorization to the browser, and lock into your workflow!
